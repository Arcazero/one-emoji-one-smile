One emoji, one smile: 🫶 — heart hands, the single emoji most likely to make a stranger smile. Two hands forming a heart is a gesture of sending warmth that anyone, anywhere, reads the same way at first glance: kind, friendly, and plainly meant to warm the person it is sent to. It is not the first smiley that comes to mind, and it carries no intimacy, irony, or in-joke — it works exactly as well coming from someone unknown. `main.py` writes exactly that one emoji, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
